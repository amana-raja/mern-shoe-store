# MERN Shoe Store 👟

A full-stack e-commerce web application for browsing women's shoes, built using the MERN stack.

## About the Project

MERN Shoe Store is a personal project created to practice full-stack web development. It allows users to explore shoe categories and browse products through a React frontend connected to a Node.js and Express backend with MongoDB.

## Features

- Dynamic shoe categories
- Product listings filtered by category
- REST API integration
- Responsive user interface
- Shopping cart functionality in progress

## Technologies Used

- **Frontend:** React.js, JavaScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **HTTP Requests:** Axios
- **Version Control:** Git and GitHub

## Getting Started

### Prerequisites

- Node.js and npm
- MongoDB connection

### Installation

1. Clone the repository:

   git clone https://github.com/amana-raja/mern-shoe-store.git

2. Open the project folder:

   cd mern-shoe-store

3. Install the dependencies in the backend and frontend folders using `npm install`.

4. Configure the required environment variables in your backend `.env` file.

5. Start the backend and frontend using the scripts defined in their respective `package.json` files.
